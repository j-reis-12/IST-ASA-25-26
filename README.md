# Analysis and Synthesis of Algorithms

> Intermediate knowledge in algorithmics and complexity, preparing the students with techniques for
> the analysis and synthesis of algorithms and data structures. Knowledge of the fundamentals of the
> design and analysis of algorithms. Analysis of the practical implementation of algorithms and data
> structures. Practical overview of applications of algorithms in Computer Science and Engineering.

## Project 1 - Optimal Amino Acid Removal Strategy

### Goal
Develop an algorithm that determines the optimal order to remove amino acids from a protein chain to
maximize total released energy, using the provided affinity matrix and potential values. The project
requires designing an efficient strategy to compute the best removal sequence, handling edge cases,
and ensuring lexicographically minimal output among optimal solutions.

## Project 2 - Path Counting in Graphs for Deliveries

### Goal
Implement an efficient algorithm to compute, for each truck in a given range, the delivery routes
assigned based on the number of distinct directed paths between intersections in a DAG. The project
focuses on graph traversal, path counting in DAGs, modular arithmetic, and producing lexicographically
ordered route assignments.

## Project 3 - Football Championship Feasibility

### Goal
Build a linear‑programming‑based module that determines, for each team in a football league, the
minimum number of remaining wins required to still be able to win the championship. The solution must
use PuLP to model constraints, incorporate match results, and compute feasibility for each team under
optimal tie‑breaking scenarios.
